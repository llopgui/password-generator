# Assets

Recursos visuales del proyecto.

## Archivos recomendados

- `icon.ico`: icono principal para Windows y build de PyInstaller.
- `icon.png`: fallback para icono en ejecución (`tkinter.iconphoto`).
- `banner.png`: imagen de apoyo visual (branding/splash).

## Convenciones

- Mantén nombres estables (`icon.ico`, `icon.png`, `banner.png`) para evitar tocar código.
- Usa imágenes cuadradas para icono (`256x256` recomendado para PNG fuente).
- Si cambias el diseño del icono, vuelve a regenerar `icon.ico`.
