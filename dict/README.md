# Diccionarios

Esta carpeta contiene los archivos `.dict` usados para generar combinaciones.

## Formato

- Un término por línea.
- Sin líneas vacías.
- UTF-8 recomendado.

## Archivos por defecto

- `santos.dict`
- `senas.dict`
- `contrasenyas.dict`

## Buenas prácticas

- Evita duplicados para mejorar diversidad.
- Mantén un mínimo de 20 entradas por archivo para mejor variabilidad.
- Usa términos memorables, pero no datos personales.
